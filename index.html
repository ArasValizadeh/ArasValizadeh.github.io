An Extended Table Detection Framework for Enhanced Recognition of Persian Tables in OCR Systems

Aras Valizadeh, Bita Baroutian, Fateme Taraghi, Zahra Mohammadi, Atefe Aghaei, and Mohsen Ebrahimi Moghaddam

Robust OCR for Persian remains difficult when pages contain complex tables. Existing OCR and vision–language methods often miss table structure or invent layout that later extraction cannot trust. We propose a modular, OCR-agnostic framework that plugs into existing systems, evaluate it on a dedicated Persian table dataset collected from real documents, and show stronger table recognition than current OCR and VLM baselines.

GRIFFIN: A Gated Relaxing Interaction-Aware Fuzzy Framework with Integrated Negation-Aware Neurocomputing to Learn Incomplete and Non-Separable Rules for Classification

Armin Salimi-Badr, Aras Valizadeh, and Mohammad Mahdi Parchamijalal

GRIFFIN is a neuro-fuzzy classifier designed for incomplete and non-separable patterns. It combines learned feature selection, a relaxation mechanism on rule activations, literal modulation, and correlation-aware rules so the model can capture feature interactions without becoming a black box. Code is available in PyTorch.
